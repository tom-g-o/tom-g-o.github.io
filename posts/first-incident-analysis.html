Investigating Suspicious Login Activity

Example SOC Investigation Walkthrough

Scenario

A user generated multiple authentication alerts during non-working hours. The SIEM triggered a suspicious login alert due to abnormal behavior.

Initial Observations

  • Login time: 03:12 AM
  • User normally logs in between 09:00–18:00
  • Multiple failed logins followed by a success
  • Source IP from a different geographic region

Log Analysis

Relevant Windows Event:

Event ID: 4625 — Failed Login
Event ID: 4624 — Successful Login
Logon Type: 10 (Remote Interactive / RDP)

Investigation Steps

  1. Verified if the user was working remotely
  2. Checked IP reputation
  3. Reviewed additional activity post-login
  4. Checked for lateral movement indicators

Findings

The IP address was associated with a VPN exit node. After contacting the user, the activity was confirmed as unauthorized.

Response

  • Account disabled
  • Password reset enforced
  • Host isolated
  • Escalated to incident response team

Conclusion

This incident highlighted the importance of monitoring authentication patterns and combining SIEM alerts with behavioral context.
